# Backend: chart-challenge
## Install 
1. ### NodeJS 
Download Nodejs
2. ### Yarn
```bash
npm install --global yarn
```
## Run project
1. ### Install node_module
```bash
yarn install
```
3. ### Run project
#### for .env.example file
```bash
yarn start
```

#### OR .env for developer (create file .env then copy content from .env.example )
```bash
yarn start:dev
```
